# Red team: the source gate (R1)

_Generated by `tests/redteam/redteam_doc.py` from the attack tests. Do not edit by hand: change the test docstring or the `xfail` mark, then re-run `env -u PYTHONPATH .venv/bin/python tests/redteam/redteam_doc.py`. `tests/redteam/test_redteam_doc.py` fails when this file is stale._

**The promise under attack** (CONSTRAINTS section 10): every fact CodeCoach shows is a word-for-word quote from the learner's materials, and every answer key is backed by one of those quotes. **Target:** `codecoach/ground` (gates a to d, the prompt check, the framing gate) and `core.public_view`. **Goal:** get a false fact past the gate. **Method:** each attack is a pytest test that builds a draft item plus passages and asserts the gate drops it. A test that exposes a real hole is `xfail(strict=True, reason="HOLE: ...")`, so the suite stays green, every hole stays visible, and fixing one turns its test red until the marker is removed.

Run: `env -u PYTHONPATH .venv/bin/python -m pytest tests/redteam -q`

## Scoreboard

- Attacks: **90**. Blocked: **85**. Holes: **5**.
- Holes, high: **4** (0 fixable, 4 honest-limit)
- Holes, medium: **1** (0 fixable, 1 honest-limit)
- Holes, low: **0** (0 fixable, 0 honest-limit)

**Severity** answers "would a learner be told something false?":

- `high`: a false fact is shown as true, or the answer key is false.
- `medium`: a right answer is graded wrong, or a wrong answer graded right, but no false fact is stated.
- `low`: nothing false is said; the item leaks its own answer, or the shown proof proves nothing.

For a *blocked* row, severity is the harm the attack would have done had it got through.

**Kind**: `fixable` means a deterministic code change closes the demonstrated attack. `honest-limit` means the gate would have to understand meaning (which fact answers the question, what a premise claims, whether two phrases mean the same), so only heuristics could shrink it. These belong in the README's honest-limit text (CONSTRAINTS section 10), next to "a question that reads the quote differently from the author". For a blocked row Kind is shown only when the row also suggests an optional improvement (an over-strict drop).
