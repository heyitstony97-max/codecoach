# Intro to C Programming (syllabus)

## Unit 1: Getting started

### Your first program

Compile and run a hello-world program with gcc. Read the compiler's error messages.

The structure of a C program: includes, main, return values.

### Variables and types

Integer and floating-point types, and how big they are.

Declaring and initialising variables. Constants and the const keyword.

### Operators and expressions

Arithmetic, comparison and logical operators. Operator precedence.

Integer division and the modulo operator. Converting between types.

## Unit 2: Control flow

### Conditionals

if, else if and else. The switch statement and fall-through.

### Loops

while, do-while and for loops. break and continue.

Tracing a loop by hand to predict its output.

### Functions

Defining and calling functions. Parameters and return values. Function prototypes.

## Unit 3: Memory

### Arrays and strings

Arrays, indexing and bounds. Strings as null-terminated char arrays.

### Pointers

What a pointer holds. Dereferencing with *, taking addresses with &.

Pointer arithmetic and arrays. Passing pointers to functions.

### Dynamic memory

malloc, calloc, realloc and free. Memory leaks and use-after-free.

## Unit 4: Structure

### Structs

Defining structs, accessing fields, passing structs to functions.

### Files

Opening, reading and writing files with fopen, fgets and fprintf.
